## API Reference
- [MikMak Commerce API Overview](https://docs.mikmak.ai/reference/mikmak-headless-commerce-api.md): The following is an overview of the MikMak Headless Commerce API (v1)
- [/commerce/v1/products/{id}](https://docs.mikmak.ai/reference/get_commerce-v1-products-id.md): Returns a list of products.
- [/commerce/v1/availabilities/{id}](https://docs.mikmak.ai/reference/get_commerce-v1-availabilities-id.md): Returns a list of store availability. Distances are in the metric system (m).
- [/commerce/v1/availabilities/cart/{id}](https://docs.mikmak.ai/reference/get_commerce-v1-availabilities-cart-id.md): Returns store-level cart availability grouped by store. Distances are in the metric system (m).
- [/commerce/v1/productcatalog/offers/models/{id}](https://docs.mikmak.ai/reference/get_commerce-v1-productcatalog-offers-models-id.md): The Offers endpoint is used to search both Online and Local retailers of a product. When Offer Location is not provided, only Online information is searched.
- [/commerce/v1/experiences/config/{id}](https://docs.mikmak.ai/reference/get_commerce-v1-experiences-config-id.md): Returns configuration metadata for a specific experience, including retailer sort order and pinned retailers.
- [/commerce/v1/experiences](https://docs.mikmak.ai/reference/get_commerce-v1-experiences.md): Returns a list of experiences available for the authenticated account.
- [/commerce/v1/products/facet](https://docs.mikmak.ai/reference/get_commerce-v1-products-facet.md): Returns product facets and optionally a productIds selection.
- [Commerce API Authentication](https://docs.mikmak.ai/reference/commerce-api-authentication.md)
- [Authorization Code Flow](https://docs.mikmak.ai/reference/authorization-code-flow.md)
- [/commerce/v1/search/products](https://docs.mikmak.ai/reference/get_commerce-v1-search-products.md): Returns paginated products matching the provided filters and optional free-text query.
- [MikMak Insights API](https://docs.mikmak.ai/reference/mikmak-insights-api.md)
